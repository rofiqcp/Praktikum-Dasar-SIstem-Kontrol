# Tugas Video Pertemuan 1

Video harus memperlihatkan:
1. identitas;
2. penjelasan open-loop dan closed-loop;
3. diagram SP-error-controller-actuator-plant-sensor;
4. P, I, D dan contoh pengaruhnya;
5. program `control_basics.py` dijalankan dari terminal;
6. minimal tiga variasi P/PI/PID;
7. pembacaan grafik;
8. penjelasan project PCB Arduino Mega;
9. pin map D5/D6/D2/D3/D8/A0/A1;
10. rencana schematic/layout;
11. kesimpulan.

Jangan hanya membaca slide; program harus benar-benar dijalankan.

## Bukti wajib
1. Gambarkan open-loop dan closed-loop serta beri contoh pemanas air dan motor.
2. Jelaskan setpoint, sensor, controller, actuator, plant dan feedback.
3. Jelaskan efek Kp, Ki, Kd, saturasi dan anti-windup secara konseptual.
4. Jalankan `examples/control_basics.py` dan tampilkan grafik.
5. Ubah minimal satu gain dan bandingkan respons.
6. Presentasikan rancangan project PCB Arduino Mega: SSR heater, L293D motor, encoder, pin map dan rencana pengujian.
7. Jelaskan minimal lima aturan keselamatan sebelum aktuator nyata dipasang.
8. Tutup dengan rencana kerja sampai checkpoint P8.

Sertakan source, screenshot grafik, diagram blok dan sketsa/diagram PCB sebagai file pendamping.
