# Pertemuan 07 — Jobsheet — LED dan ADC dari MATLAB


1. Install MATLAB Support Package for Arduino Hardware.
2. Sambungkan Mega via USB.
3. Jalankan `a=arduino();` atau tentukan port/board bila diperlukan.
4. Jalankan `led_adc.m`.
5. Ubah LED D13 ON/OFF.
6. Hubungkan potensiometer/sumber analog aman ke A0.
7. Plot A0 selama 20 s.
8. Simpan data ke CSV.
9. Catat perioda sampling aktual rata-rata/min/max.

Lakukan test pada PCB project: 5V/GND, LED status, A0, D8 dummy LED, D5/D6 tanpa motor dahulu. Dokumentasikan hasil bring-up.
