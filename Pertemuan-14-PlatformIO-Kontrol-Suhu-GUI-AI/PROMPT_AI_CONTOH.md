# Prompt AI contoh P14

> Audit firmware Arduino Mega PlatformIO PID temperatur ini. Requirement: sensor A0, SSR D8, output OFF on boot, RUN eksplisit, PID 0..100%, conditional anti-windup, derivative on measurement, window SSR 500..10000 ms, over-temperature, invalid sensor, heartbeat timeout 2.5 s. Serial 115200. Jangan menghapus failsafe untuk menyederhanakan kode. Setelah audit, buat daftar failure mode sebelum memberi patch.

Untuk GUI: dukung demo mode, serial refresh, connect, Start/Stop, heartbeat, gain, dua live graph, fault, CSV/XLSX/JPG dan response metrics.
