# Pertemuan 13 — Jobsheet — PlatformIO Sensor Bring-up


1. Install VS Code + PlatformIO.
2. Buka `examples/mega_sensors` sebagai project.
3. Build dan upload.
4. Monitor serial; pastikan `ms,adc,voltage,count,angle_deg,rpm` berubah wajar.
5. Putar motor dua arah manual.
6. Jalankan `examples/python_serial_plotter/plot_serial.py`.
7. Simpan screenshot dan CSV.
8. Minta AI menambah satu fitur kecil (mis. moving average ADC), lalu jelaskan diff dan pengujiannya.
