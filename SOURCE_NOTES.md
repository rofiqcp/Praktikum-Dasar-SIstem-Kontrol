# Catatan Penyusunan Materi

Repository ini menggunakan struktur dokumentasi yang meniru pola `Praktikum-Sistem-Embedded`: Materi, Jobsheet, tugas/project, dan contoh program per modul.

Materi yang menjadi basis isi P1-P13 meliputi:
- pengenalan sistem kontrol dan PID;
- MATLAB/Simulink, transfer function dan pemodelan;
- Autonics TK4S-T4RN untuk ON-OFF/PID dan DAQMaster;
- PWM + encoder Arduino Mega melalui Simulink;
- PID discrete, speed, position, anti-windup;
- autotuning Sinestream, Superposition, PRBS;
- PlatformIO Arduino Mega dan GUI Python.

Perubahan kurikulum yang diterapkan:
- plant temperatur menggunakan **pemanas air**, bukan lampu pijar;
- P1 memasukkan briefing project PCB Arduino Mega untuk SSR + L293D + encoder;
- P2 dasar MATLAB;
- P3 transfer function tiga plant;
- P4 PID MATLAB termasuk PID block manual;
- P5 Autonics pemanas air dengan stopwatch dan Excel;
- P6 DAQMaster;
- P8/P12/P16 menggunakan `Project.md` menggantikan `TugasVideo.md`;
- P14-P16 dikembangkan sebagai kelanjutan integrasi hardware/software agar jalur 16 pertemuan lengkap.
