# Tugas Video Pertemuan 05 — Autonics TK4S + Pemanas Air: Pengambilan Data Manual Stopwatch

## Format
Durasi disarankan 8–15 menit. Tampilkan layar, hardware bila ada, dan wajah/presentasi secukupnya.

## Isi Wajib
1. Jelaskan respon sistem, open-loop dan closed-loop
2. Jelaskan operasi PV/SV Autonics dan parameter yang digunakan
3. Perlihatkan plant pemanas air dan metode stopwatch
4. Tampilkan 3 variasi hysteresis dan grafik
5. Tampilkan percobaan PID time-proportional
6. Analisis overshoot, settling time dan error steady state

## Bukti Running
- tampilkan proses menjalankan program/model dari awal;
- ubah minimal 2 parameter/setpoint;
- tampilkan grafik atau data hasil;
- jelaskan minimal 3 parameter karakteristik respon sistem;
- simpulkan konfigurasi yang paling baik dan alasannya.
