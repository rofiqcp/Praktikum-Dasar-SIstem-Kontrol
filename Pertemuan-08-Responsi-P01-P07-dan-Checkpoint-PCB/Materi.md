# Pertemuan 08 — Responsi P1–P7 dan Checkpoint Project PCB


Pertemuan ini tidak menambah topik besar baru. Fokusnya memastikan setiap mahasiswa benar-benar memahami dan dapat menjalankan materi P1–P7.

## Bank kompetensi
- sistem kontrol, feedback, open/closed loop;
- P/I/D dan respon sistem;
- MATLAB dasar;
- transfer function heater/speed/position;
- PID MATLAB dan blok manual;
- Autonics ON/OFF/PID, manual logging, DAQMaster;
- MATLAB–Arduino LED/ADC;
- progress schematic/layout/bring-up PCB.

## Bentuk responsi
Dosen dapat memilih pertanyaan acak, meminta modifikasi kode langsung, atau meminta mahasiswa menjelaskan diagram/waveform tanpa melihat catatan.
