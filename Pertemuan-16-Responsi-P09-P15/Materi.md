# Pertemuan 16 — Responsi P9–P15 — Integrasi Kontrol Suhu dan Motor


Pertemuan final menguji pemahaman end-to-end, bukan menghafal source.

## Ruang lingkup
- Arduino Mega temperature PID + SSR;
- encoder, RPM, position;
- MATLAB PID speed/position;
- PlatformIO project structure;
- interrupt/timing/anti-windup/filter;
- protocol serial;
- Python GUI;
- CSV/JPG;
- metrik respon sistem;
- penggunaan AI yang dapat dipertanggungjawabkan;
- keselamatan hardware.

## Bentuk ujian
Pertanyaan acak, live modification parameter/code, debugging scenario, dan demo hardware. Mahasiswa harus dapat menunjukkan jalur data dari sensor sampai actuator dan dari telemetry sampai file hasil.
